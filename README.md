# SPECTRA poster supplement

Supplementary material for the poster *SPECTRA: Domain-Specific Accelerator for Ultra-Low-Field Magnetic Resonance
Imaging (ULF-MRI) Reconstruction* (Adnane Gdihi, Dr. Lennart Johnsson, University of Houston): the full chip, the
conjugate-gradient algorithm, how each number was measured, and every measured value behind the poster's figures.

Live page: https://adnanegdihi.github.io/

`index.html` is self-contained: its fonts and figures are embedded.
